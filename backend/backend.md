# VigilCloud Backend

FastAPI service — ingests hazard/shock events, runs the cross-node consensus check, computes the Cargo Risk Score, and pushes live updates over WebSocket.

## Setup

```bash
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install fastapi uvicorn sqlalchemy paho-mqtt websockets python-multipart numpy opencv-python ultralytics requests
uvicorn main:app --reload
```

Server runs at `http://localhost:8000`. Interactive API docs at `http://localhost:8000/docs` (auto-generated by FastAPI — use this to test endpoints without writing curl commands).

## ⚠️ If you pull a new `database.py`

SQLite's `create_all()` only creates tables that don't exist yet — it never alters existing ones. If a schema update adds/renames a column on an existing table (`hazard_events`, `nodes`), **delete `vigilcloud.db`** before restarting the server, or you'll get `OperationalError: table X has no column named Y`. This is dev data, always safe to delete.

```bash
rm vigilcloud.db
uvicorn main:app --reload   # recreates fresh
```

## Data model

| Table | Purpose | Status |
|---|---|---|
| `hazard_events` | Confirmed road hazards (pothole/fog/fire/stalled) | v1, working |
| `nodes` | Sensor nodes — `node_type`: `infra_road` \| `truck_mounted` | v1 + v2 extension |
| `fleet_operators` | Logistics company / tenant | v2 |
| `trucks` | Truck belonging to a fleet operator | v2 |
| `shipments` | In-transit cargo run, carries `cargo_risk_score` | v2 |
| `shock_events` | ADXL345 g-force reading above threshold, linkable to a causing hazard | v2 |

Full field-level spec: see `VigilCloud_SRS_v2.docx`, Section 6.

## API reference

### Working now

| Method | Route | Purpose |
|---|---|---|
| GET | `/` | Health check, reports whether `best.pt` (YOLO weights) is loaded |
| POST | `/ingest` | Receives a sensor/hazard event from a node or the simulator |
| GET | `/hazards` | Last 50 confirmed hazards, newest first |
| GET | `/hazards/near?lat=&lng=&radius_km=` | Confirmed hazards within radius of a driver's position |
| POST | `/detect` | Upload an image, get YOLO pothole detections (mock response until `best.pt` exists) |
| GET | `/stats` | Total confirmed alerts + breakdown by hazard type |
| WS | `/ws/live` | Live push of confirmed events to connected dashboards |

### Planned (v2 pivot)

| Method | Route | Purpose | Depends on |
|---|---|---|---|
| GET | `/shipments/{id}/risk` | Cargo Risk Score + component breakdown | `Shipment`, `ShockEvent` tables (done) |
| GET | `/fleet/{operator_id}/trucks` | Live truck/shipment status for a fleet | Fleet dashboard fork |
| POST | `/shipments/{id}/report` | PDF/CSV incident report for a shipment | — |
| GET | `/predict/segment/{id}` | LSTM forward hazard probability | `ml/train_lstm.py` |
